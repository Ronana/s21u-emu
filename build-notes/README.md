# Build notes

One file per emulator (e.g. `retroarch.md`, `dolphin.md`). Each covers:

- Source repo + exact commit/tag built
- Toolchain versions (JDK, SDK, NDK, CMake, Gradle)
- Build commands, copy-pasteable
- Problems hit and fixes
- APK size / install result on device
- Any custom compiler flags, and benchmark comparison vs the release build
